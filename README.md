## :pencil2: Dear Journal -a peaceful journaling place for everyone :herb:
 **Dear Journal** is a website where you can write journal entries and document your journey toward deeper self-understanding.
 On this website, you can keep your journal private, or choose to share your entries in the public section. There, people can connect in a gentle and modest way by sending hearts and hugs to the entries that emotionally resonate with them.

## Features
-Write, save, update, and delete journal entries using the Trix Editor  
-Add hashtags to entries  
-Tag favorite entries  
-Set public/private mode per user  
-Set each journal entry to be public or private (for public users)  
-Send and receive simple reactions: heart and hug  
-Filter entries by date, reactions, hashtags, and keywords  
-Pagination for journal entries 
-Email verification required to access the public section  
-Google/Facebook OAuth login
-Fully responsive UI for desktop and mobile  
-Custom font style and screen size per user  
-Custom night mode and color theme options per user 

Note: Facebook Login is implemented and functional, but currently in development mode. Test access can be provided upon request.
